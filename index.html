Info
Cara kerja & pertanyaan umum
01
Deteksi ID
Kamu tempel angka ID atau link create.roblox.com, sistem otomatis ambil angka ID-nya.
02
Ambil Data
ID dikirim ke API resmi Roblox (economy.roblox.com) untuk ambil nama, tipe, harga, dan pembuat aset.
03
Susun Link
Nama item diubah jadi slug, lalu digabung dengan ID untuk membentuk link create.roblox.com yang lengkap.
04
Tampilkan
Semua hasil muncul di panel: nama, pembuat, harga, dan link siap salin atau dibuka langsung.
Data ini dari mana?

Langsung dari API publik Roblox (economy.roblox.com), bukan tebakan atau database pihak ketiga.

Kenapa pencarian kadang gagal?

Biasanya karena aset sudah dihapus, di-set privat oleh pembuatnya, ID salah ketik, atau API Roblox lagi membatasi permintaan.

Perlu login akun Roblox?

Enggak. Tempel ID, klik Cari, selesai. Gak ada akun atau data pribadi yang diminta.

Bisa dipakai buat aset apa saja?

Bisa untuk model, decal, gamepass, animasi, dan tipe aset lain yang punya halaman di create.roblox.com.
